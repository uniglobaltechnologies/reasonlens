## Key Points

- The 2025 cycle is closed; AWS states the **2026-2027 cycle opens in spring 2026**.
- Applicants can submit **one application per cycle** and select **one category**.
- Educational institutions are called out as excluded from Imagine Grant eligibility; nonprofits/charities are the intended applicant type.
- If institution-led, AWS points to the Education Equity Initiative as an alternative program.

## Award Package Notes (Verify at Submission)

Award amounts vary by region/cycle and can change. Verify in the live application portal before final submission.

- UK page (current public page):
  - Go Further, Faster: up to $100,000 unrestricted + up to $25,000 AWS credits
  - Pathfinder: up to $100,000 unrestricted + up to $100,000 AWS credits
- US FAQ/proposal guidelines (2024 references):
  - Go Further, Faster: up to $150,000 unrestricted + up to $100,000 AWS credits
  - Momentum to Modernize: up to $50,000 unrestricted + up to $20,000 AWS credits
  - Pathfinder: up to $200,000 unrestricted + up to $100,000 AWS credits
